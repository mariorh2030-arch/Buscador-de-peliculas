[Ver en vivo](https://mariorh2030-arch.github.io/Buscador-de-peliculas)

## ✨ Funcionalidades
- Búsqueda en tiempo real mientras escribes
- Muestra poster, título, calificación y año de cada película
- Resultados en español
- Diseño oscuro inspirado en Netflix

## 🛠️ Tecnologías
- HTML5
- CSS3
- JavaScript Vanilla
- [TMDB API](https://www.themoviedb.org/)

## ⚙️ Cómo usarlo localmente
1. Clona el repositorio
   git clone https://github.com/mariorh2030-arch/Buscador-de-peliculas.git
2. Obtén tu API key gratis en themoviedb.org
3. Reemplaza API_KEY en script.js con tu key
4. Abre index.html en tu navegador
